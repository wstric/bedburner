# BedBurner Assembly Instructions

## Heater Heatsink

Starting with a commodity aluminum 50mm x 50mm x 20mm heatsink.
These often come with thermal tape preapplied which will need to be removed.

Variants are provided for thermal switch, thermal fuse or thermistor
fail-safe options are given.

Symmetrical screw holes are modeled but only about half are necessary.
One could save some wear on your bits/taps if you machine the ones needed
for each block.

Similarly, the thermal fuse pocket is not as necessary for secure mounting as
those for the PTC and thermal switch so it can be skipped if desired.

Technical drawings are provided for clarity in [/Drawing/block](/Drawing/block).

### CNC Mill (Recommended)

It is unlikely to be cost effective have the block machined from raw stock and
commercial services are unlikely start from a purchased heatsink.
The best option if you have a CNC mill or "a friend with a CNC mill".

Files are provided as [STEP](/CAD) or [DXF](/Drawing/block).

### Hand Tools

The prototype unit blocks were made with hand tools and it can be done if you
have the resolve.

3D printable [guides and templates](/STL/block_template) are provided to use with
hand drills and trim routers. The guides and templates fit snugly onto the sides of
the heatsink.

Drill guide uses 2.0mm bit. Step up to 2.5mm bit for M3 tap.
Have multiple drill bits and end taps. You will likely break multiple.
Drill/tap depth should be approximately 4.5mm.

The router templates requires a 5/16" OD Router bushing. A 1/16th inch bit is necessary
to get corner relief. Templates to use A 1/8th inch bit are also provided to quickly hog
out material and just let the smaller bit clean up the edges and corners.

> [!CAUTION]
> Carbide trim router bits can cut aluminum very well but doing so requires skill and
> setup to do so safely. Do not attempt if you do not have experience using this tool.

## Heater Bracket

Cut and bent from plain 16ga mild steel these parts are straight forward to source.
This really makes sense to outsource to laser cutting services. The prototype units
were ordered from SendCutSend. At the time, a set of parts wouldn't get to the
minimum order amount.

Mirror pairs can be made using the same file by bend up and bend down.

Files are provided as [STEP](/CAD) or [DXF](/Drawing/bracket).

Technical drawings are provided for clarity in [/Drawing/block](/Drawing/bracket).

## Component Straps

These are very simple parts made plain 22ga steel and can me made by hand if
desired but I would just include them in the order for the heater brackets.

Separate files are provided for shorter thermal switch and longer ptc straps.

Only [DXF](/Drawing/strap) files are provided.
